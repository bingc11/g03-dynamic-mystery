Issue #5 的严格真实模型双案、56 条固定意图、原始候选和判别后结果见本轮验收。以下保留 Issue #4 的历史对照。[Issue #5 验收](../ACCEPTANCE.md#issue-5-云端验收)

本次比较使用同一套规则与四组固定情境，覆盖雾港案、宫廷案、两种角色关系配置、玩家委托和事件触发反应。规则与 Mock 用于验证可重复路径。真实模型组让 DeepSeek 处理意图、计划与接收方回应，记录由程序执行后的结果。真模型首轮于 2026 年 11 月 25 日 21:22–21:23（北京时间）在 Codex Cloud 运行，模型为 `deepseek-flash`。[情境定义](../tools/npc_scenarios.json) · [模拟程序](../tools/simulate_cases.py)

## 复现

在仓库根目录，用同一个 Python 环境运行下列命令。运行第三条命令前按服务端说明配置 DeepSeek。

```sh
python tools/simulate_cases.py --driver mock --output /tmp/g03-mock.json
python tools/simulate_cases.py --driver rules --output /tmp/g03-rules.json
python tools/simulate_cases.py --driver llm --max-provider-attempts 58 --output /tmp/g03-deepseek.json
python tools/simulate_cases.py --driver llm --contrast --max-provider-attempts 7 --output /tmp/g03-roles.json
```

`--case harbor_blackout` 和 `--case example_4` 可筛选要评测的案件。真实评测需要显式的运行级调用上限，角色运行时仍受单次请求和每局预算限制。报告包含每局事件检查、任务状态、基线路径差异、请求摘要和响应候选 ID。[模型配置与预算](ARCHITECTURE.md)

## 真实决策的后果

| 情境 | 发生的事 | 对调查的影响 |
| --- | --- | --- |
| `harbor-contact` | DeepSeek 为宋屿选择联系阮岑，作为接收者的阮岑独立选择披露，玩家随后向阮岑追问 | 获得关于西门出入的目击主张。林遥把「替我核对这两份证词」判为需澄清，本轮未取回复电日志。 |

### 复测、角色对照和浏览器实测

首轮漏掉两项核查线索后，意图判断加入角色有权执行的行动标签，并说明比对材料属于新委托。用原句复测 `harbor-contact` 和 `palace-records`，两处都取得了有来源的核查记录，分别是复电日志和御史台副册。所选两组达到 3/3 条预设线索，16 次请求全部成功，使用 18,007 / 153 token，累计 17.612 秒。该次雾港复测中，阮岑先确认有人联系过，要求继续追问才能具名。[两组复测报告](evidence/issue4/deepseek-compare-recheck.json) · [完整调查示例](CLASSROOM.md)

宫廷案在独立的新局分别向三人出示同一证物并说「请看遗失的宫闱秘录」。四次真实请求全部成功。三人的行动和后果由各自可见的知识、目标和授权解释。[同一输入对照记录](evidence/issue4/deepseek-role-contrast.json)

| 人物 | 角色所知和调查优先项 | DeepSeek 选择及程序执行 |
| --- | --- | --- |
| 太平公主 | 关注秘录去向，信任掌握登记的御史 | `consult_registry`。私下联系御史，御史独立选择转述，记为主张。 |
| 御史大夫 | 依赖原始凭据，掌握和可查阅副册 | `inspect_registry`。核查副册，写入有来源的对象读取事件。 |
| 张昌宗 | 优先留意香囊，缺少登记查阅权 | `defer`。暂缓行动，保留出示和决定两条事件。 |

雾港案另用同一句仓库委托做五次真实请求的对照。林遥缺少委托权限，选择暂缓并建议找宋屿。用只移除阮岑目击知识的测试局委托宋屿，宋屿仍实际去问，阮岑选择保留，任务因没有可回报的内容而失败。原始案情中阮岑知道目击记录，生产浏览器实测选择披露。[雾港权限与知识对照](evidence/issue4/deepseek-role-controls.json)

真实生产浏览器验证了宋屿接受委托并联系阮岑，阮岑独立决定披露，玩家追问获知联系者。访客看到显式公开的主张。玩家可更正一次错误指控、结案并主动展开解释。该局 4 次决策请求全部成功，使用 4,418 / 37 token，累计 4.185 秒，无规则回退。早期隔离进程缺少网络代理配置，记录到 3 次连接错误、2 次超时和 3 次规则回退，仍可完成任务。启动器继承云端网络配置后，重跑取得上述真实链路。另一次较长的追问得到澄清，记录保留在同一报告。[浏览器调用摘要](evidence/issue4/deepseek-browser.json) · [结案截图](evidence/issue4/live-harbor-closed.png) · [对应事件](evidence/issue4/live-harbor-closed.jsonl) · [第二席位截图](evidence/issue4/harbor-second-seat.png) · [对应事件](evidence/issue4/harbor-second-seat.jsonl)
